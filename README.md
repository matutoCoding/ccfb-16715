# 暗场散射检测配方仿真系统

晶圆表面缺陷暗场检测的浏览器端仿真与检测配方设计工具。散射计算与成像均在 WebGPU 计算着色器中完成, 配方与数据存于 IndexedDB。

## 功能

- **晶圆与膜层**: 衬底 + 多层膜厚度/折射率录入, 表面粗糙度按 ABC 模型功率谱密度 (PSD) 录入, 自动计算 RMS 粗糙度与 TIS
- **缺陷库**: 颗粒 (尺寸+材料)、坑、划痕 (长/宽/深)、残留四类模板
- **光路配方**: 入射角/方位角/偏振/波长, 窄角+宽角双收集通道, 收集立体角可调并实时显示
- **散射成像**: 整片 300mm 晶圆暗场图 (GPU 计算着色器成像), 缺陷亮点 + 雾度底噪, 滚轮缩放/拖拽平移/点选缺陷看米氏角分布
- **检出分析**: 按 SNR 计算各缺陷类型的检出率-尺寸曲线 (POD), D50 表
- **配方对比**: 最多 3 套配方并排比 POD 曲线, 自动推荐平均检出率最高者
- **导出**: 配方参数 JSON + 检出能力报告 Markdown
- **设置**: 仿真参数, GPU 信息, 米氏散射 GPU vs 解析级数校验 (验收: 相对误差 < 1%)

## 物理模型

- 颗粒/坑/残留: 米氏散射解析级数 (Bohren-Huffman 递推), CPU 参考实现 + WGSL 计算着色器实现互相对照
- 雾度: Rayleigh-Rice BRDF 标量近似, PSD 用 ABC (K-correlation) 模型, 半球积分与 TIS 公式交叉验证
- 划痕: 沟槽工程模型, σ ∝ L·w·(w/λ)·(d/λ)·|n²-1|², 半球均匀角分布
- 膜层: 特征矩阵法反射率, 顶层折射率作为坑散射的介质
- 检出: SNR = S/√(S+B+r²), POD 为阈值处误差函数

## 运行

```bash
pnpm install
pnpm dev
```

需要支持 WebGPU 的浏览器 (Chrome/Edge 113+)。

## 测试 (无需安装依赖, Node 24+ 直接跑)

```bash
node scripts/test_mie.ts          # 米氏级数: 瑞利极限/消光悖论/无吸收 Qext==Qsca
node --loader ./scripts/alias_loader.mjs scripts/test_physics.ts   # 膜层/雾度/端到端仿真
```

## 验收

1. 米氏散射 GPU vs 解析级数: 应用内「设置 → 运行 GPU vs 解析级数校验」, 6 组用例相对误差 < 1%
2. 整片晶圆暗场图 < 10s: CPU 回退路径全流程约 0.4s (3328 缺陷), GPU 路径更快, 页面实时显示物理计算与 GPU 成像耗时

## 目录

```
src/
  physics/    米氏级数 / 膜层特征矩阵 / PSD 雾度 / 收集立体角积分
  gpu/        WebGPU 设备, WGSL 着色器 (米氏表, 晶圆成像)
  engine/     仿真编排 (剂量->信号->SNR->POD), GPU 校验
  data/       材料库, 演示数据播种 (300mm 晶圆, 3328 缺陷)
  state/      响应式状态 + IndexedDB 回写
  pages/      晶圆膜层 / 缺陷库 / 光路配方 / 散射成像 / 检出分析 / 设置
  components/ SVG 折线图, 晶圆图画布
scripts/      Node 自检脚本
```
